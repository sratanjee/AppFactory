## 2. The job

One sentence, in the user's words, describing the single thing this app does.

> "I want to put a 48-hour wait between wanting something and buying it so that I stop spending money on things I regret."

**Who pays:** A 25–35 year old who has TikTok Shop and Amazon on their phone, is trying to pay down a credit card, and just realized their "little treats" added up to $400 last month.
**Where they gather:** r/Frugal, r/nobuy, and #nospendchallenge / #underconsumptioncore on TikTok.
**Why they'd pay instead of using a free thing:** A notes app has no lock and no timer — nothing stops you deciding early. Budget apps track money after it's gone. Impulse is the only thing that sits in the gap before the purchase, and the lifetime Saved total is a number they'll want to keep growing and screenshot.

## 3. Screens (3–5 max)

| # | Screen | Purpose | Key interaction |
|---|---|---|---|
| 1 | Home | Show lifetime Saved total (hero), the Waiting list with live countdowns, and the Ready-to-decide list | Tap "Add something" opens Add sheet; on a Ready item tap Bought or Skipped (dialog confirm); Skipped animates the Saved number up |
| 2 | Add sheet | Capture the thing they almost bought | Name + price required, note + link optional, wait-period picker (24h free · 48h free · 72h Pro · 7d Pro); Save locks the item and starts the timer with a medium haptic |

| 4 | History | Everything decided, newest first, grouped by month with a Saved subtotal per month | Segmented control All / Skipped / Bought; free tier sees last 30 days, scrolling past it triggers paywall |
| 5 | Settings | Preferences and account | Default wait period, currency override, reminders toggle, Export CSV (Pro), Restore purchases, Reset all data (double confirm) |

Empty states and error states are required for every screen; the Builder writes them from this table.

## 4. Data model

Local-first by default. List entities and fields. Mark anything that must sync or hit the shared backend.

```
Item
  id: uuid
  name: string
  priceMinor: int          // minor units (cents) in `currency`
  currency: string         // ISO 4217, from locale at creation
  note: string?            // single line
  link: string?            // URL, opened in external browser
  createdAt: datetime
  decideAt: datetime       // createdAt + waitHours
  decision: enum?          // bought | skipped; null while undecided
  decidedAt: datetime?

Settings
  defaultWaitHours: int    // 48
  currencyOverride: string?
  remindersEnabled: bool   // true once permission granted

// Derived, never stored: savedTotal = sum(priceMinor where decision == skipped)
// Deleting an undecided item never touches totals.
```

## 8. Design notes

Keep to `DESIGN_GUIDE.md`. Only list what's specific to this app.

- Accent color (one hex): #1D9A6C
- Icon concept (one sentence): A shopping bag outline with a small pause symbol where the handle meets the bag.
- Tone of copy (e.g. calm, blunt, encouraging): Calm and matter-of-fact; no shame copy on Bought items, no streaks, no confetti.
- Anything that must feel different from sibling apps in this category: The Saved number is the product — it's the largest thing on Home, counts up over ~600 ms when it changes, and is the only place accent color appears besides the Add button and selected tab. Countdowns tick per minute, not per second.
